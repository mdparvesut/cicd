## 2. SSH Key Setup

### 2.1 Why SSH Keys?

**SSH Key** = Secure way to authenticate to servers without passwords

```
Your Computer  ←→  SSH Keys  ←→  VM
```

**Security benefits:**
- ✅ More secure than passwords
- ✅ Cannot be brute-forced
- ✅ Can be easily revoked
- ✅ Required for automated deployment

### 2.2 Generate SSH Key Pair

#### **On Linux/macOS/WSL:**

```bash
# Generate 4096-bit RSA key
ssh-keygen -t rsa -b 4096 -C "your.email@ut.ee"

# When prompted:
# Enter file in which to save the key: [Press Enter for default]
# Enter passphrase: [Optional - press Enter to skip or add passphrase for extra security]
```

**Output:**
```
Generating public/private rsa key pair.
Your identification has been saved in /home/username/.ssh/id_rsa
Your public key has been saved in /home/username/.ssh/id_rsa.pub
```

**Files created:**
- `~/.ssh/id_rsa` - **Private key** (keep secret! 🔒)
- `~/.ssh/id_rsa.pub` - **Public key** (share with servers)

#### **On Windows (PowerShell):**

```powershell
# Generate key
ssh-keygen -t rsa -b 4096 -C "your.email@ut.ee"

# Keys will be saved in:
# C:\Users\YourUsername\.ssh\id_rsa
# C:\Users\YourUsername\.ssh\id_rsa.pub
```

### 2.3 View Your Public Key

```bash
# Linux/macOS/WSL
cat ~/.ssh/id_rsa.pub

# Windows (PowerShell)
type C:\Users\YourUsername\.ssh\id_rsa.pub
```

**Example output:**
```
ssh-rsa AAAAB3NzaC1yc2EAAAADAQABAAACAQDZm3... your.email@ut.ee
```

**⚠️ IMPORTANT:**
- Copy the **ENTIRE** output (starts with `ssh-rsa`, ends with your email)
- This is your public key - safe to share
- Never share your private key (`id_rsa`)

### 2.4 Add SSH Key to ETAIS

1. **Login to ETAIS:** https://minu.etais.ee
2. **Click on your profile** (top right corner)
3. **Go to "SSH Keys"**
4. **Click "+ Add SSH key"**
5. **Fill in:**
   - **Name:** `My Laptop` (descriptive name)
   - **Public key:** Paste your public key from above
6. **Click "Add key"**

### 2.5 Verify SSH Key Permissions (Important!)

```bash
# Check permissions (should be 600 for private key)
ls -l ~/.ssh/id_rsa

# If permissions are wrong, fix them:
chmod 600 ~/.ssh/id_rsa
chmod 644 ~/.ssh/id_rsa.pub
```

**Correct permissions:**
- `id_rsa` (private): `600` (-rw-------)
- `id_rsa.pub` (public): `644` (-rw-r--r--)

## 3. Creating Virtual Machine

### 3.1 Check VM Name Availability

**IMPORTANT:** VM name becomes your domain name!

```
VM name: reddit-clone
Domain: reddit-clone.cloud.ut.ee
```

**Check if name is available:**

```bash
# Test if domain is taken
dig @ns1.cloud.ut.ee reddit-clone.cloud.ut.ee

# If ANSWER SECTION is empty → name is available ✅
# If ANSWER SECTION shows an IP → name is taken ❌
```

**Choose a unique name:**
- Only lowercase letters and numbers
- No special characters (no õäöü, spaces, underscores)
- Examples: `reddit-clone-team5`, `reddit-alpha`, `reddit2025`

### 3.2 Create VM in ETAIS

1. **Login to ETAIS:** https://minu.etais.ee

2. **Click "+ Add resource"** (left sidebar)

3. **Select:**
   - **Organization:** DevOps course
   - **Project:** Your team's project

4. **Scroll to "VMs" category**

5. **Choose "Virtual machine in <VPC-name>"**

6. **Configure VM:**

   **Operating System:**
   - **Image:** `CentOS 9 Stream` (recommended) or `Ubuntu 22.04`
   
   **Resources:**
   - **Flavor:** `m1.medium` (2 vCPU, 4 GB RAM) or custom
   
   **Storage:**
   - **System Volume Type:** `prod3 (IOPS intensive SSD)`
   - **System Volume Size:** `40 GB`
   - **Data Volume Type:** `prod3 (IOPS intensive SSD)`
   - **Data Volume Size:** `60 GB`
   
   **SSH Key:**
   - Select your SSH key (the one you added earlier)
   
   **Network:**
   - **Networks:** `<VPC-name>-sub-net`
   - **Auto-assign Floating IP:** ✅ Check this
   
   **Security Groups:**
   - ✅ `default`
   - ✅ `ssh`
   - ✅ `ping`
   
   **VM Details:**
   - **VM name:** `reddit-clone-team5` (your unique name)
   - **Description:** `Reddit Clone - Team 5 - DevOps 2025`

7. **Review everything and click "Create"**


### 4.2 Update System

```bash
# For CentOS 9

# For Ubuntu
sudo apt update && sudo apt upgrade -y

# Reboot if kernel was updated
```

### 4.3 Set Hostname

```bash
# Set a friendly hostname
sudo hostnamectl set-hostname reddit-clone

# Verify
hostname
# Output: reddit-clone
```

### 4.4 Create Application User

**Why separate user?**
- ✅ Security: Don't run apps as root
- ✅ Isolation: Limit damage if compromised
- ✅ Best practice

```bash
# Create user for running applications
sudo useradd -m -s /bin/bash appuser

# Add to necessary groups
sudo usermod -aG wheel appuser  # CentOS (for sudo)
# Or for Ubuntu:
# sudo usermod -aG sudo appuser

# Create .ssh directory for appuser
sudo mkdir -p /home/appuser/.ssh
sudo cp ~/.ssh/authorized_keys /home/appuser/.ssh/
sudo chown -R appuser:appuser /home/appuser/.ssh
sudo chmod 700 /home/appuser/.ssh
sudo chmod 600 /home/appuser/.ssh/authorized_keys

# Test connection as appuser
exit
ssh appuser@reddit-clone-team5.cloud.ut.ee
```

### 4.5 Create Application Directories

```bash
# Create directories for applications
sudo mkdir -p /opt/reddit-clone/backend
sudo mkdir -p /opt/reddit-clone/frontend
sudo mkdir -p /var/log/reddit-clone

# Set ownership
sudo chown -R appuser:appuser /opt/reddit-clone
sudo chown -R appuser:appuser /var/log/reddit-clone

# Verify
ls -la /opt/reddit-clone
```

**Directory structure:**
```
/opt/reddit-clone/
├── backend/          # Backend binary and configs
├── frontend/         # Frontend static files
└── /var/log/reddit-clone/  # Application logs
```

## 6. Database Setup on VM

### 6.1 Install PostgreSQL

```bash
# CentOS 9 - Install PostgreSQL 15
sudo dnf install -y postgresql-server postgresql-contrib

# Initialize database
sudo postgresql-setup --initdb

# Start and enable PostgreSQL
sudo systemctl start postgresql
sudo systemctl enable postgresql

# Check status
sudo systemctl status postgresql
```

### 6.2 Configure PostgreSQL

```bash
# Switch to postgres user
sudo -i -u postgres

# Access PostgreSQL
psql

# Inside PostgreSQL shell:
```

```sql
-- Create database
CREATE DATABASE reddit_clone;

-- Create user with password
CREATE USER reddit_user WITH PASSWORD 'your_secure_password_here';

-- Grant privileges
GRANT ALL PRIVILEGES ON DATABASE reddit_clone TO reddit_user;

-- For PostgreSQL 15+, also grant schema privileges
\c reddit_clone
GRANT ALL ON SCHEMA public TO reddit_user;

-- Verify
\l                    -- List databases
\du                   -- List users

-- Exit
\q
```

```bash
# Exit postgres user
exit
```

### 6.3 Configure PostgreSQL Authentication

```bash
# Edit pg_hba.conf
sudo vim /var/lib/pgsql/data/pg_hba.conf

# Find these lines:
# local   all             all                                     peer
# host    all             all             127.0.0.1/32            ident

# Change to:
local   all             all                                     md5
host    all             all             127.0.0.1/32            md5
host    all             all             ::1/128                 md5
```

**Save and exit** (`:wq` in vim)

### 6.4 Configure PostgreSQL to Listen

```bash
# Edit postgresql.conf
sudo vim /var/lib/pgsql/data/postgresql.conf

# Find and modify:
listen_addresses = 'localhost'

# Save and exit
```

### 6.5 Restart PostgreSQL

```bash
# Restart to apply changes
sudo systemctl restart postgresql

# Verify connection
psql -h localhost -U reddit_user -d reddit_clone

# You should be prompted for password
# If successful, you'll see:
reddit_clone=>

# Exit
\q
```

### 6.6 Create Database Connection Config

```bash
# Create .env file for backend
vim /opt/reddit-clone/backend/.env
```

```bash
# Database Configuration
DB_HOST=localhost
DB_PORT=5432
DB_USER=reddit_user
DB_PASSWORD=your_secure_password_here
DB_NAME=reddit_clone
DB_SSLMODE=disable

# Server Configuration

# JWT Configuration

# CORS
CORS_ALLOWED_ORIGINS=https://reddit-clone-team5.cloud.ut.ee
```

**Secure the file:**
```bash
chmod 600 /opt/reddit-clone/backend/.env
```

## 7. Web Server Configuration (Nginx)

### 7.1 Install Nginx

```bash
# Install Nginx
sudo dnf install -y nginx

# Start and enable
sudo systemctl start nginx
sudo systemctl enable nginx

# Check status
sudo systemctl status nginx
```

### 7.2 Create Nginx Configuration

```bash
# Create configuration file
sudo vim /etc/nginx/conf.d/reddit-clone.conf
```

**Add this configuration:**

```nginx
# /etc/nginx/conf.d/reddit-clone.conf

# Backend API
upstream backend {
    server 127.0.0.1:8080;
}

# Redirect HTTP to HTTPS
server {
    listen 80;
    listen [::]:80;
    server_name reddit-clone-team5.cloud.ut.ee;

    # Certbot will add SSL configuration here later
    location / {
        return 301 https://$server_name$request_uri;
    }
}

# HTTPS Server (will be configured after SSL certificate)
server {
    listen 443 ssl http2;
    listen [::]:443 ssl http2;
    server_name reddit-clone-team5.cloud.ut.ee;

    # SSL certificates (will be added by Certbot)
    # ssl_certificate /etc/letsencrypt/live/reddit-clone-team5.cloud.ut.ee/fullchain.pem;
    # ssl_certificate_key /etc/letsencrypt/live/reddit-clone-team5.cloud.ut.ee/privkey.pem;

    # SSL configuration
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_prefer_server_ciphers on;
    ssl_ciphers 'ECDHE-ECDSA-AES128-GCM-SHA256:ECDHE-RSA-AES128-GCM-SHA256';

    # Security headers
    add_header Strict-Transport-Security "max-age=31536000; includeSubDomains" always;
    add_header X-Frame-Options "SAMEORIGIN" always;
    add_header X-Content-Type-Options "nosniff" always;
    add_header X-XSS-Protection "1; mode=block" always;

    # Logs
    access_log /var/log/nginx/reddit-clone-access.log;
    error_log /var/log/nginx/reddit-clone-error.log;

    # Root directory for frontend
    root /opt/reddit-clone/frontend;
    index index.html;

    # Frontend - serve React app
    location / {
        try_files $uri $uri/ /index.html;
    }

    # Backend API
    location /api {
        proxy_pass http://backend;
        proxy_http_version 1.1;
        
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        
        proxy_cache_bypass $http_upgrade;
        proxy_buffering off;
    }

    # WebSocket support
    location /ws {
        proxy_pass http://backend;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        
        proxy_read_timeout 86400;
    }
}
```

**Important:** Replace `reddit-clone-team5.cloud.ut.ee` with your actual domain!

## 8. SSL/TLS Certificate Setup

### 8.1 Why SSL/TLS?

**Requirements:**
- ✅ Course requires HTTPS (TLS protocol)
- ✅ Certificates must be valid (not self-signed)
- ✅ Browsers trust the certificate

**Solution:** Use Let's Encrypt (free, automated, trusted)

### 8.2 Install Certbot

```bash
# Install Certbot
sudo dnf install -y certbot python3-certbot-nginx

# Verify installation
certbot --version
```

### 8.3 Obtain SSL Certificate

```bash
# Get certificate using Certbot
sudo certbot --nginx -d reddit-clone-team5.cloud.ut.ee

# You'll be prompted:
# 1. Email address: your.email@ut.ee
# 2. Agree to Terms of Service: Yes
# 3. Share email with EFF: Your choice (No is fine)
```

**Certbot will:**
1. Verify you control the domain
2. Obtain certificate from Let's Encrypt
3. Automatically configure Nginx
4. Set up automatic renewal

**Expected output:**
```
Successfully received certificate.
Certificate is saved at: /etc/letsencrypt/live/reddit-clone-team5.cloud.ut.ee/fullchain.pem
Key is saved at: /etc/letsencrypt/live/reddit-clone-team5.cloud.ut.ee/privkey.pem
```

### 8.4 Test Certificate Renewal

```bash
# Dry run to test renewal
sudo certbot renew --dry-run

# Should show:
# Congratulations, all simulated renewals succeeded
```

### 8.5 Verify HTTPS Works

```bash
# Test from your local machine
curl https://reddit-clone-team5.cloud.ut.ee

# Or open in browser:
# https://reddit-clone-team5.cloud.ut.ee
```

**Expected:** Nginx welcome page or 502 Bad Gateway (normal, backend not running yet)

### 8.6 Certificate Auto-Renewal

Certbot automatically sets up renewal. Verify:

```bash

```

Certificates auto-renew every 60 days.

## 9. Firewall and Security Configuration

### 9.1 Configure Firewall Rules

```bash
# Check firewall status
sudo firewall-cmd --state

# Allow HTTP (port 80)
sudo firewall-cmd --permanent --add-service=http

# Allow HTTPS (port 443)
sudo firewall-cmd --permanent --add-service=https

# Allow SSH (should already be open)
sudo firewall-cmd --permanent --add-service=ssh

# Reload firewall
sudo firewall-cmd --reload

# Verify rules
sudo firewall-cmd --list-all
```

**Expected output:**
```
services: cockpit dhcpv6-client http https ssh
```

### 9.2 Configure Security Groups in ETAIS

**Open required ports:**

1. **Go to ETAIS** → Resources → VM → Your VM

2. **Click "Networking" tab**

3. **Manage Security Groups**

4. **Create new security group for web:**
   - **Name:** `web`
   - **Description:** `HTTP and HTTPS traffic`

5. **Add rules to `web` security group:**

   **Rule 1 - HTTP:**
   - Direction: `Ingress`
   - Ethernet type: `IPv4`
   - IP protocol: `TCP`
   - Destination port: `80`
   - Remote CIDR: `0.0.0.0/0`

   **Rule 2 - HTTPS:**
   - Direction: `Ingress`
   - Ethernet type: `IPv4`
   - IP protocol: `TCP`
   - Destination port: `443`
   - Remote CIDR: `0.0.0.0/0`

6. **Attach `web` security group to your VM:**
   - VM → Actions → Update Security Groups
   - Add `web` to the list
   - Click Submit

### 9.3 Security Best Practices

#### **Disable Root Login via SSH:**

```bash
# Edit SSH config
sudo vim /etc/ssh/sshd_config

# Find and modify:
PermitRootLogin no
PasswordAuthentication no
PubkeyAuthentication yes

# Save and restart SSH
sudo systemctl restart sshd
```

#### **Configure Fail2Ban (Optional but Recommended):**

```bash
# Install Fail2Ban
sudo dnf install -y fail2ban fail2ban-systemd

# Configure
sudo cp /etc/fail2ban/jail.conf /etc/fail2ban/jail.local
sudo vim /etc/fail2ban/jail.local

# Enable SSH protection:
[sshd]
enabled = true
port = ssh
logpath = /var/log/secure
maxretry = 5
bantime = 3600

# Start Fail2Ban
sudo systemctl start fail2ban
sudo systemctl enable fail2ban

# Check status
sudo fail2ban-client status
```

#### **Keep System Updated:**

```bash
# Enable automatic security updates
sudo dnf install -y dnf-automatic

# Configure for security updates only
sudo vim /etc/dnf/automatic.conf

# Set:
upgrade_type = security
apply_updates = yes

# Enable and start
sudo systemctl enable --now dnf-automatic.timer
```
