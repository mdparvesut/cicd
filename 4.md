## 9. Troubleshooting Deployment

### 9.1 Common Pipeline Errors

#### **Error: "Permission denied (publickey)"**

```
ssh: connect to host reddit-clone-team5.cloud.ut.ee port 22: Permission denied
```

**Solutions:**

1. **Check SSH key is added to VM:**
```bash
ssh appuser@reddit-clone-team5.cloud.ut.ee
cat ~/.ssh/authorized_keys
# Should contain your deployment key
```

2. **Check GitLab variable is correct:**
- Settings → CI/CD → Variables
- `SSH_PRIVATE_KEY_BASE64` should be base64 encoded

3. **Re-encode key:**
```bash
cat ~/.ssh/id_rsa_gitlab_deploy | base64 -w 0
# Copy output and update GitLab variable
```

#### **Error: "Host key verification failed"**

```
Host key verification failed.
```

**Solution:** Already handled by `StrictHostKeyChecking no` in SSH config. If still occurring:

```yaml
# In .gitlab-ci.yml, add:
before_script:
  - ssh-keyscan ${VM_HOST} >> ~/.ssh/known_hosts
```

#### **Error: "No such file or directory"**

```
scp: /opt/reddit-clone/backend/reddit-clone-backend: No such file or directory
```

**Solution:** Create directory on VM:

```bash
ssh appuser@reddit-clone-team5.cloud.ut.ee
sudo mkdir -p /opt/reddit-clone/backend
sudo chown -R appuser:appuser /opt/reddit-clone
```

#### **Error: "systemctl: command not found"**

```
sudo systemctl start reddit-backend
sudo: systemctl: command not found
```

**Solution:** Service not yet created. Follow section 6.2 to create systemd service.

### 9.2 Common Service Errors

#### **Service fails to start**

```bash
# Check detailed error
sudo systemctl status reddit-backend -l

# Check logs
sudo journalctl -u reddit-backend -n 50
```

**Common causes:**

1. **Port already in use:**
```bash
# Check what's using port 8080
sudo netstat -tulpn | grep 8080

# Kill the process if needed
sudo kill -9 <PID>
```

2. **Environment variables missing:**
```bash
# Check .env file exists
ls -la /opt/reddit-clone/backend/.env

# Verify contents
cat /opt/reddit-clone/backend/.env
```

3. **Database connection failed:**
```bash
# Test PostgreSQL is running
sudo systemctl status postgresql

# Test connection manually
psql -h localhost -U reddit_user -d reddit_clone
```

4. **Binary not executable:**
```bash
# Check permissions
ls -l /opt/reddit-clone/backend/reddit-clone-backend

# Fix if needed
chmod +x /opt/reddit-clone/backend/reddit-clone-backend
```

#### **Service starts but crashes immediately**

```bash
# View detailed logs
sudo journalctl -u reddit-backend -f

# Common issues:
# - Database migration needed
# - Missing configuration
# - Code panic/error
```

**Run migrations:**
```bash
cd /opt/reddit-clone/backend
./reddit-clone-backend migrate up
```

### 9.3 Common Nginx Errors

#### **502 Bad Gateway**

```
502 Bad Gateway
nginx/1.20.1
```

**Meaning:** Nginx can't connect to backend

**Solutions:**

1. **Check backend is running:**
```bash
sudo systemctl status reddit-backend
```

2. **Check backend is listening on port 8080:**
```bash
curl http://localhost:8080/health
```

3. **Check Nginx upstream configuration:**
```bash
sudo nginx -t
sudo systemctl restart nginx
```

#### **404 Not Found for API calls**

**Check Nginx configuration:**
```bash
sudo vim /etc/nginx/conf.d/reddit-clone.conf

# Verify location /api block exists:
location /api {
    proxy_pass http://backend;
    ...
}
```

#### **Frontend loads but API calls fail (CORS errors)**

**Check browser console:**
```
Access-Control-Allow-Origin missing
```

**Solution:** Update backend CORS configuration:

```bash
# In .env file on VM
CORS_ALLOWED_ORIGINS=https://reddit-clone-team5.cloud.ut.ee

# Restart backend
sudo systemctl restart reddit-backend
```

### 9.5 Rollback Procedure

If deployment breaks production:

#### **Option 1: Use Rollback Job (Manual)**

1. Go to GitLab → CI/CD → Pipelines
2. Find the failed pipeline
3. Click on `rollback` job
4. Click "Play" button (▶️)
5. Wait for rollback to complete

#### **Option 2: Manual Rollback**

```bash
# Connect to VM
ssh appuser@reddit-clone-team5.cloud.ut.ee

# Backend rollback
sudo systemctl stop reddit-backend
mv /opt/reddit-clone/backend/reddit-clone-backend.backup /opt/reddit-clone/backend/reddit-clone-backend
sudo systemctl start reddit-backend

# Frontend rollback
sudo rm -rf /opt/reddit-clone/frontend
sudo mv /opt/reddit-clone/frontend.backup /opt/reddit-clone/frontend
sudo systemctl reload nginx
```

#### **Option 3: Redeploy Previous Version**

1. Find last working commit in GitLab
2. Checkout that commit
3. Push to trigger redeployment

```bash
# Find last good commit
git log --oneline

# Create branch from that commit
git checkout -b hotfix/rollback <commit-hash>

# Push to main (triggers deployment)
git push origin hotfix/rollback:main
```

**Create alert script:**

```bash
# On VM
sudo vim /opt/reddit-clone/alert-on-failure.sh
```

```bash
#!/bin/bash
# alert-on-failure.sh - Alert if service fails

SERVICE="reddit-backend"

if ! systemctl is-active --quiet $SERVICE; then
    echo "ALERT: $SERVICE is not running!" | logger -t reddit-alert
    # Optional: send email, slack notification, etc.
    systemctl restart $SERVICE
fi
```

```bash
chmod +x /opt/reddit-clone/alert-on-failure.sh

# Add to crontab
crontab -e
# Add:
*/5 * * * * /opt/reddit-clone/alert-on-failure.sh
```
