## 🎯 Part 1: Plan Your Deployment Strategy

Here's what happens when you push code:

```
1. GitLab Pipeline Runs
   ↓
2. Build Stage: Creates frontend (dist/) and backend (binary)
   ↓
3. Test Stage: Runs unit tests
   ↓
4. Deploy Stage:
   - Connects to VM via SSH
   - Copies frontend files to /opt/reddit-clone/frontend/
   - Copies backend binary to /opt/reddit-clone/backend/
   - Runs database migrations
   - Restarts backend service
   - Caddy automatically serves everything
```

## 🔧 Part 3: Create Systemd Service for Backend

This makes your backend run automatically and restart if it crashes.

```bash
# Create systemd service file
nano /etc/systemd/system/reddit-clone-backend.service
```

**Add this content:**

```ini
[Unit]
Description=Reddit Clone Backend API
After=network.target postgresql.service
Requires=postgresql.service

[Service]
Type=simple
User=root
WorkingDirectory=/opt/reddit-clone/backend
ExecStart=/opt/reddit-clone/backend/reddit-clone-api
Restart=always
RestartSec=5

# Environment variables (secrets)
Environment="DB_PASSWORD=your_secure_password_here"
Environment="JWT_SECRET=your_jwt_secret_change_this"
Environment="GIN_MODE=release"
Environment="CONFIG_PATH=/opt/reddit-clone/backend/config/production.yaml"

# Logging
StandardOutput=append:/opt/reddit-clone/logs/backend.log
StandardError=append:/opt/reddit-clone/logs/backend-error.log

[Install]
WantedBy=multi-user.target
```

**Save and exit**

### Enable the service (but don't start yet - no binary exists):

```bash
# Reload systemd to recognize new service
systemctl daemon-reload

# Enable service to start on boot
systemctl enable reddit-clone-backend.service

# Check service status (it will fail for now - no binary yet)
systemctl status reddit-clone-backend.service
```

## 🌐 Part 4: Configure Caddy Web Server

Caddy will:
- Serve your React frontend (static files)
- Proxy API requests to your Go backend
- Automatically handle SSL certificates

```bash
# Backup original Caddyfile
cp /etc/caddy/Caddyfile /etc/caddy/Caddyfile.backup

# Edit Caddyfile
nano /etc/caddy/Caddyfile
```

**Replace everything with this:**

```caddyfile
# Replace with YOUR actual domain
reddit-clone-teamx.cloud.ut.ee {
    # Enable automatic HTTPS
    # Caddy will automatically get Let's Encrypt certificate
    
    # Serve frontend static files
    root * /opt/reddit-clone/frontend
    
    # Try to serve files, fall back to index.html for SPA routing
    try_files {path} /index.html
    
    # Proxy API requests to backend
    handle /api/* {
        reverse_proxy localhost:8080
    }
    
    # Enable file serving
    file_server
    
    # Enable gzip compression
    encode gzip
    
    # Access logs
    log {
        output file /opt/reddit-clone/logs/caddy-access.log
    }
}
```

**Important:** Replace `reddit-clone-teamx.cloud.ut.ee` with YOUR actual VM domain!

**Save and exit**

### Reload Caddy:

```bash
# Test configuration
caddy validate --config /etc/caddy/Caddyfile

# Reload Caddy (don't restart - reload is smoother)
systemctl reload caddy

# Check status
systemctl status caddy
```

## 📜 Part 5: Create Deployment Script on VM

This script will be called by GitLab to deploy your app.

```bash
# Create deployment script
nano /opt/reddit-clone/deploy.sh
```

**Add this content:**

```bash
#!/bin/bash

# Reddit Clone Deployment Script
# This script deploys the application on the VM

set -e  # Exit on any error

echo "=========================================="
echo "Starting Reddit Clone Deployment"
echo "Time: $(date)"
echo "=========================================="

# Variables
DEPLOY_DIR="/opt/reddit-clone"
BACKEND_DIR="$DEPLOY_DIR/backend"
FRONTEND_DIR="$DEPLOY_DIR/frontend"
LOG_DIR="$DEPLOY_DIR/logs"

# Create log directory if it doesn't exist
mkdir -p "$LOG_DIR"

# 1. Stop backend service
echo "→ Stopping backend service..."
systemctl stop reddit-clone-backend.service || true

# 2. Backup old binary (optional)
if [ -f "$BACKEND_DIR/reddit-clone-api" ]; then
    echo "→ Backing up old binary..."
    mv "$BACKEND_DIR/reddit-clone-api" "$BACKEND_DIR/reddit-clone-api.backup" || true
fi

# 3. The new files are already copied by GitLab CI/CD
# We just need to set proper permissions

echo "→ Setting permissions..."
chmod +x "$BACKEND_DIR/reddit-clone-api"
chmod -R 755 "$FRONTEND_DIR"

# 4. Run database migrations
echo "→ Running database migrations..."
cd "$BACKEND_DIR"

# Check if migrations directory exists
if [ -d "migrations" ]; then
    # Using go-migrate CLI (we'll install this next)
    migrate -path migrations -database "postgresql://reddit_user:${DB_PASSWORD}@localhost:5432/reddit_clone?sslmode=disable" up || echo "⚠ Migrations failed or already applied"
else
    echo "⚠ No migrations directory found"
fi

# 5. Start backend service
echo "→ Starting backend service..."
systemctl start reddit-clone-backend.service

# 6. Wait for service to start
sleep 2

# 7. Check if backend is running
if systemctl is-active --quiet reddit-clone-backend.service; then
    echo "✓ Backend service is running"
else
    echo "✗ Backend service failed to start!"
    echo "→ Checking logs..."
    journalctl -u reddit-clone-backend.service -n 20 --no-pager
    exit 1
fi

# 8. Reload Caddy to pick up any config changes
echo "→ Reloading Caddy..."
systemctl reload caddy

# 9. Health check
echo "→ Running health check..."
sleep 3
HEALTH_CHECK=$(curl -s -o /dev/null -w "%{http_code}" http://localhost:8080/api/health || echo "000")

if [ "$HEALTH_CHECK" = "200" ]; then
    echo "✓ Health check passed (HTTP $HEALTH_CHECK)"
else
    echo "⚠ Health check returned HTTP $HEALTH_CHECK"
fi

echo "=========================================="
echo "Deployment completed successfully!"
echo "=========================================="
```

**Save and exit**

### Make script executable:

```bash
chmod +x /opt/reddit-clone/deploy.sh
```

## 🚀 Part 7: Update `.gitlab-ci.yml` with Deploy Stage

Now let's update your pipeline to actually deploy to the VM.

**On your local machine**, edit `.gitlab-ci.yml`:

```yaml
stages:
  - build
  - test
  - deploy

variables:
  GIT_DEPTH: 1

###############################################
# BUILD STAGE
###############################################

build-frontend:
  stage: build
  image: node:18-alpine
  
  script:
    - cd frontend
    - npm ci --cache .npm --prefer-offline
    - npm run build
  
  artifacts:
    paths:
      - frontend/dist/
    expire_in: 1 hour
  
  cache:
    key: frontend-dependencies
    paths:
      - frontend/.npm/
  
  only:
    - main

build-backend:
  stage: build
  image: golang:1.21-alpine
  
  script:
    - cd backend
    - go mod download
    # Build static binary
    - CGO_ENABLED=0 GOOS=linux GOARCH=amd64 go build -o reddit-clone-api ./cmd/api
  
  artifacts:
    paths:
      - backend/reddit-clone-api
      - backend/migrations/  # Include migrations
      - backend/config/      # Include config (if you have it in repo)
    expire_in: 1 hour
  
  cache:
    key: backend-dependencies
    paths:
      - /go/pkg/mod/
  
  only:
    - main

###############################################
# TEST STAGE
###############################################

test-backend:
  stage: test
  image: golang:1.21-alpine
  
  before_script:
    - apk add --no-cache git bc
  
  script:
    - cd backend
    - go test ./... -coverprofile=coverage.out -covermode=count
    
    - |
      COVERAGE=$(go tool cover -func=coverage.out | grep total | awk '{print $3}' | sed 's/%//')
      echo "Test coverage: ${COVERAGE}%"
      
      if (( $(echo "$COVERAGE < 50" | bc -l) )); then
        echo "ERROR: Coverage ${COVERAGE}% is below 50%"
        exit 1
      fi
  
  artifacts:
    paths:
      - backend/coverage.out
    expire_in: 1 week
  
  coverage: '/total:\s+\(statements\)\s+(\d+\.?\d*)%/'
  
  only:
    - main

###############################################
# DEPLOY STAGE
###############################################

deploy-to-vm:
  stage: deploy
  image: alpine:latest
  
  before_script:
    # Install dependencies
    - apk add --no-cache openssh-client rsync
    
    # Set up SSH
    - eval $(ssh-agent -s)
    - chmod 400 "$SSH_PRIVATE_KEY"
    - ssh-add "$SSH_PRIVATE_KEY"
    - mkdir -p ~/.ssh
    - echo -e "Host *\n\tStrictHostKeyChecking no\n\n" > ~/.ssh/config
  
  script:
    - echo "=========================================="
    - echo "Deploying to ${VM_HOST}"
    - echo "=========================================="
    
    # 1. Create directories on VM (if they don't exist)
    - |
      ssh ${VM_USER}@${VM_HOST} "
        mkdir -p /opt/reddit-clone/backend
        mkdir -p /opt/reddit-clone/frontend
        mkdir -p /opt/reddit-clone/logs
      "
    
    # 2. Copy frontend files
    - echo "→ Copying frontend files..."
    - rsync -avz --delete frontend/dist/ ${VM_USER}@${VM_HOST}:/opt/reddit-clone/frontend/
    
    # 3. Copy backend binary
    - echo "→ Copying backend binary..."
    - scp backend/reddit-clone-api ${VM_USER}@${VM_HOST}:/opt/reddit-clone/backend/
    
    # 4. Copy migrations (if they exist)
    - echo "→ Copying database migrations..."
    - |
      if [ -d "backend/migrations" ]; then
        rsync -avz backend/migrations/ ${VM_USER}@${VM_HOST}:/opt/reddit-clone/backend/migrations/
      else
        echo "⚠ No migrations directory found"
      fi
    
    # 5. Run deployment script on VM
    - echo "→ Running deployment script..."
    - |
      ssh ${VM_USER}@${VM_HOST} "
        export DB_PASSWORD='${DB_PASSWORD}'
        /opt/reddit-clone/deploy.sh
      "
    
    # 6. Verify deployment
    - echo "→ Verifying deployment..."
    - |
      ssh ${VM_USER}@${VM_HOST} "
        echo 'Backend service status:'
        systemctl status reddit-clone-backend.service --no-pager -l
        echo ''
        echo 'Recent logs:'
        tail -n 10 /opt/reddit-clone/logs/backend.log || echo 'No logs yet'
      "
    
    - echo "=========================================="
    - echo "✓ Deployment completed successfully!"
    - echo "→ Application URL: https://${VM_HOST}"
    - echo "=========================================="
  
  only:
    - main
  
  # Deploy depends on build jobs completing
  dependencies:
    - build-frontend
    - build-backend
```

## 🔧 Part 9: Update Backend to Use Environment Variables

Make sure your backend code reads these environment variables. 

**Example for your backend (adjust based on your structure):**

```go
// In your config loading code (using Viper)

package config

import (
    "github.com/spf13/viper"
    "os"
)

func LoadConfig() error {
    // Set config file
    viper.SetConfigName("production")
    viper.SetConfigType("yaml")
    viper.AddConfigPath("/opt/reddit-clone/backend/config")
    viper.AddConfigPath("./config") // For local development
    
    // Read config file
    if err := viper.ReadInConfig(); err != nil {
        return err
    }
    
    // Override with environment variables
    viper.AutomaticEnv()
    
    // Explicitly bind environment variables
    if dbPassword := os.Getenv("DB_PASSWORD"); dbPassword != "" {
        viper.Set("database.password", dbPassword)
    }
    
    if jwtSecret := os.Getenv("JWT_SECRET"); jwtSecret != "" {
        viper.Set("jwt.secret", jwtSecret)
    }
    
    return nil
}
```

## 🐛 Troubleshooting Common Issues

### Issue 1: "502 Bad Gateway" when accessing /api/*

**Cause:** Backend not running or crashed

**Solution:**
```bash
# On VM:
systemctl status reddit-clone-backend.service

# If stopped, start it:
systemctl start reddit-clone-backend.service

# Check logs:
journalctl -u reddit-clone-backend.service -n 50

# Common issue: database connection
# Make sure DB_PASSWORD is set correctly in /etc/systemd/system/reddit-clone-backend.service
```

### Issue 2: Frontend shows but is blank/white screen

**Cause:** Wrong build path or routing issue

**Solution:**
```bash
# Check if files exist:
ls -la /opt/reddit-clone/frontend/

# Should see: index.html, assets/, etc.

# Check browser console (F12) for errors

# Common issue: BASE_URL in Vite config
# In your vite.config.js:
export default defineConfig({
  base: '/',  // Should be '/' not '/dist/'
})
```

### Issue 3: SSL certificate not working

**Cause:** Caddy can't reach Let's Encrypt or port 80/443 blocked

**Solution:**
```bash
# Check Caddy logs:
journalctl -u caddy -n 50

# Make sure ports are open:
ufw status

# Check ETAIS security group 'web' is attached

# Force certificate renewal:
systemctl restart caddy
```

### Issue 4: Pipeline deploy fails with "Permission denied"

**Cause:** SSH key issues

**Solution:**
```bash
# On VM, check authorized_keys:
cat /root/.ssh/authorized_keys

# Should contain the public key matching SSH_PRIVATE_KEY

# Check permissions:
chmod 700 /root/.ssh
chmod 600 /root/.ssh/authorized_keys
```

### Issue 5: Database migrations fail

**Cause:** Wrong connection string or migrations path

**Solution:**
```bash
# Test migration manually on VM:
cd /opt/reddit-clone/backend

migrate -path migrations \
  -database "postgresql://reddit_user:your_password@localhost:5432/reddit_clone?sslmode=disable" \
  up

# Check if migrations directory exists:
ls -la migrations/

# Common issue: password contains special characters
# URL-encode special characters in password
```
